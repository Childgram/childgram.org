- Android-клиент находится в независимом репозитории `android/`.
- Основа: Telegram **12.10.6 (7112)**, коммит
  `f2908b14133bbffbf7ab04f641ecb5bfaf533242`.
- Локальная рабочая ветка: `childgram-dev`, отслеживает `origin/master`.
  Изменения Childgram опубликованы в коммите `95dd1d82`; настройка ресурсов

  Содержимое старых файлов загружается по запросу (`blob:none` у `upstream`);
  для ещё не скачанных исторических версий потребуется сеть. Текущие исходники
  и закреплённые подмодули находятся локально.
- Первый опубликованный prerelease: **0.1.0-alpha.1**, код версии **1**,
  пакет **`org.childgram`**, ARM64.
- Выпускной ключ существует в `android/.local/signing/`; публичный отпечаток
  закреплён в [release-certificate.sha256](https://github.com/Childgram/cg-android/blob/master/dev/release-certificate.sha256).
- Ранее выполненные проверки и ограничения описаны в
  [руководстве Android](https://github.com/Childgram/cg-android/blob/master/dev/README.md). Их даты не означают, что
  выпуск прошёл все проверки стабильного релиза.

## Репозиторий Android

3 октября 2026 года GitHub API подтвердил, что
[Childgram/cg-android](https://github.com/Childgram/cg-android) — публичный форк:
`fork: true`, `parent.full_name: DrKLO/Telegram`, `source.full_name: DrKLO/Telegram`.
Основная ветка на GitHub — `master`. Созданный ранее самостоятельный репозиторий
`Childgram/childgram-android` для Android-кода не используется.

Android-код остаётся в корне отдельного репозитория. Локально настроены два remote:

```text
upstream  https://github.com/DrKLO/Telegram.git
origin    https://github.com/Childgram/cg-android.git
```

Исходники Childgram отправлены в форк с сохранением upstream-истории.
Общие документы и сайт опубликованы отдельно в
[Childgram/childgram.org](https://github.com/Childgram/childgram.org).
APK собран отдельным workflow, проверен и опубликован владельцем как prerelease.
Инструкция GitHub: [создание форка](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo).

## До публикации

- [x] Настроить GitHub Fork и проверить `origin` / `upstream`.
- [x] Проверить diff Childgram к закреплённому upstream, состав коммита и отсутствие
  локальных ключей, реквизитов, журналов и пользовательских данных.
- [x] Закоммитить исходники и инструменты, выбрать выпускной тег; собрать APK
  именно из публикуемого состояния исходников.
- [ ] Сохранить выпускной ключ вместе с паролем в защищённой резервной копии
  вне этого компьютера. Сохранение папки при переносе не заменяет резервную копию.
- [ ] Завершить оформление вступительных экранов Telegram; иконка приложения
  и системная заставка уже используют общий логотип Childgram из `branding/`.
- [x] Собрать release в Docker, проверить подпись, установить APK и выполнить
  `check-release --device` и `emulator --release smoke`, осмотреть экран и логи.
- [ ] Проверить обновление поверх предыдущего APK с сохранением данных,
  входящие сообщения, звонки, фон, блокировку экрана, Doze, смену сети и перезагрузку.
  Текущие проверки доступа и запуска не подтверждают фоновую доставку.
- [ ] Выполнить ручные сценарии ограничений доступа и восстановления сети;
  указать известные ограничения первого выпуска.
- [x] Подготовить публикацию: точный коммит и тег, версию upstream, diff изменений,
  инструкцию сборки, результаты проверок, APK, его SHA-256 и отпечаток сертификата.
  Тестовые APK из `.local/checks/` не распространять.

Перенос рабочей директории сам по себе не является выпуском приложения.

## Проверка кеширования GitHub-сборок, 3 октября 2026 года

Два последовательных запуска `verify_only` на новых `ubuntu-24.04` runners

| Подготовка Docker-образа | 3 мин 46 с | 1 мин 22 с |
| Gradle | 25 мин 7 с | 11 мин 37 с |
| Попадания в кеш C/C++ | 0 из 1730 | 1730 из 1730 (100%) |

Повторное задание быстрее примерно на **45%**. Зависимости и native-кеш
восстановлены за **5 с** из кеша предыдущего коммита; Docker подтвердил

Замер относится к текущему коду и окружению, не гарантирует такое же время
