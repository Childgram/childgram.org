# Первый Android-релиз

## Исходная точка

- Android-клиент находится в независимом репозитории `android/`.
- Основа: Telegram **12.10.6 (7112)**, коммит
  `f2908b14133bbffbf7ab04f641ecb5bfaf533242`.
- Текущая рабочая ветка: `childgram-dev`; изменения Childgram пока не закоммичены.
- История коммитов Telegram догружена до корня, shallow-ограничение снято.
  Содержимое старых файлов загружается по запросу (`blob:none` у `upstream`);
  для ещё не скачанных исторических версий потребуется сеть. Текущие исходники
  и закреплённые подмодули находятся локально.
- Кандидат: **0.1.0-alpha.1**, код версии **1**, пакет **`org.childgram`**, ARM64.
- Выпускной ключ существует в `android/.local/signing/`; публичный отпечаток
  закреплён в [release-certificate.sha256](../android/dev/release-certificate.sha256).
- Ранее выполненные проверки и ограничения описаны в
  [руководстве Android](../android/dev/README.md). Их даты не означают, что
  текущий кандидат прошёл все проверки публичного релиза.

## Репозиторий Android

3 октября 2026 года GitHub API подтвердил, что
[Childgram/cg-android](https://github.com/Childgram/cg-android) — публичный форк:
`fork: true`, `parent.full_name: DrKLO/Telegram`, `source.full_name: DrKLO/Telegram`.
Основная ветка на GitHub — `master`. Созданный ранее самостоятельный репозиторий
`Childgram/childgram-android` для Android-кода не используется.

Android-код остаётся в корне отдельного репозитория. Локально настроены два remote:

```text
upstream  https://github.com/DrKLO/Telegram.git
origin    https://github.com/Childgram/cg-android.git
```

Изменения Childgram и APK ещё не отправлены. У верхнего репозитория документов
будет собственный remote, если понадобится его публикация.
Инструкция GitHub: [создание форка](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo).

## До публикации

- [x] Настроить GitHub Fork и проверить `origin` / `upstream`.
- [ ] Проверить diff Childgram к закреплённому upstream, состав коммита и отсутствие
  локальных ключей, реквизитов, журналов и пользовательских данных.
- [ ] Закоммитить исходники и инструменты, выбрать выпускной тег; собрать APK
  именно из публикуемого состояния исходников.
- [ ] Сохранить выпускной ключ вместе с паролем в защищённой резервной копии
  вне этого компьютера. Сохранение папки при переносе не заменяет резервную копию.
- [ ] Завершить оформление вступительных экранов Telegram; иконка приложения
  и системная заставка уже используют общий логотип Childgram из `branding/`.
- [ ] Собрать release в Docker, проверить подпись, установить APK и выполнить
  `check-release --device` и `emulator --release smoke`, осмотреть экран и логи.
- [ ] Проверить обновление поверх предыдущего APK с сохранением данных,
  входящие сообщения, звонки, фон, блокировку экрана, Doze, смену сети и перезагрузку.
  Текущие проверки доступа и запуска не подтверждают фоновую доставку.
- [ ] Выполнить ручные сценарии ограничений доступа и восстановления сети;
  указать известные ограничения первого выпуска.
- [ ] Подготовить публикацию: точный коммит и тег, версию upstream, diff изменений,
  инструкцию сборки, результаты проверок, APK, его SHA-256 и отпечаток сертификата.
  Тестовые APK из `.local/checks/` не распространять.

Перенос рабочей директории сам по себе не является выпуском приложения.

## Обновления, черновики и сайт, 3 октября 2026 года

- В release включён собственный updater: постоянная лента
  `https://update.childgram.org/android.json`, проверка при открытии приложения
  раз в 6 часов и кнопка в настройках. Загрузка начинается по нажатию, установка
  проходит через Android. Dev не обновляется release-пакетом. Надписи окна —
  Childgram; суффикс `alpha` остаётся только в имени версии.
- Переиспользованы штатные UI-компоненты Telegram; они перенесены из beta-модуля
  в общую библиотеку с отдельными именами. Поведение обычного Telegram и beta
  вне Childgram сохранено. Перед установкой проверяются URL релиза, размер,
  SHA-256, пакет, версия, совместимость SDK и подпись установленного приложения.
- Подготовлены Actions для подписанной Docker-сборки в **черновик** релиза
  и для публикации ленты после ручной публикации. Черновики исключены; опубликованные
  prerelease входят в ленту по наибольшему code. До первого релиза — `available:false`.
- Подготовлен отдельный статический сайт `childgram.org` в верхнем репозитории.
  Он получает версию и APK-ссылку из той же ленты. Без JavaScript или при сетевой
  ошибке остаётся рабочая ссылка на GitHub Releases. Общий SVG используется
  напрямую. Экспорт содержит только публичные файлы сайта.
- Итоговые Docker-сборки прошли: release — **9 мин 3 с**, dev — **4 мин 20 с**.
  Подпись, ARM64, пакет и отсутствие debug-флага в release проверены.
  SHA-256 APK: `049b6af9dcd9d7d10d3ce6448cee45bd759d9ccc04d082a0cea71c0b7c03b27b`.
- На установленном release прошли **144 проверки**, включая **30 проверок**
  обновления. Проверены JSON, версии, лимит загрузки, отмена, хеш, размер,
  неправильная версия APK, доступ через FileProvider. APK с теми же package/version,
  но другим тестовым ключом отклонён. Посторонний APK не устанавливался.
